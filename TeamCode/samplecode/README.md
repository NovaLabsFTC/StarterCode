# NovaLabs shared sample code
Reference snippets shared by NovaLabs teams. This folder is NOT compiled:
to use a snippet, copy it into your own TeamCode/src/main/java/... folder
and fix the package line.
Each folder belongs to one team: ftc<team-number> (for example ftc14691).
Coaches bring a team's samples in with the "Pull samples from a team" workflow,
through a reviewed pull request. Don't edit other teams' folders.
